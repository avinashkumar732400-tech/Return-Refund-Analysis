# Return & Refund Analysis Dashboard

## Project Overview

The **Return & Refund Analysis Dashboard** is a data analytics project designed to understand customer returns, refund amounts, order performance, and return reasons across different sales channels.

The dashboard provides a clear view of business performance through interactive charts, KPI cards, tables, and filters. It helps identify the product categories with the highest returns, the most common return reasons, and the relationship between discounts and return rates.

The main goal of this project is to turn raw sales and return data into meaningful insights that can help businesses reduce product returns, improve customer satisfaction, and make better decisions.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)
- **Total Orders:** Displays the total number of orders.
- **Return Orders:** Shows the number of orders that were returned.
- **Return Rate:** Measures the percentage of orders returned.
- **Refund Amount:** Displays the total refund amount.

### 2. Sales Channel Analysis
Analyzes returns across different sales channels:
- Marketplace
- Mobile App
- Offline Store
- Website

This helps compare return performance across different purchasing channels.

### 3. Category-Wise Analysis
Compares total orders and returned units across product categories, including electronics, fashion, home products, beauty, sports, and books.

### 4. Refund and Return Trends
Displays monthly refund amounts and return orders to help understand changes in refund activity over time.

### 5. Return Reason Analysis
Identifies the most common reasons for product returns, such as:
- Wrong Size
- Damaged Product
- Defective Product
- Late Delivery
- Quality Issue
- Changed Mind
- Product Not as Expected

### 6. Discount vs. Return Rate
Uses a scatter plot to analyze the relationship between average product discounts and return rates. This can help identify products that may require further investigation.

### 7. Detailed Product Analysis
Provides product-level information, including total orders, returned units, return rate, refund amount, and average return days.

### 8. Interactive Filters
Users can filter the dashboard by date range and sales channel to explore specific periods and business segments.

## Tools and Technologies

- **Microsoft Power BI:** Dashboard creation and visualization
- **Power Query:** Data cleaning and transformation
- **DAX:** Measures, KPI calculations, and business metrics
- **Data Visualization:** KPI cards, donut charts, bar charts, line charts, scatter plots, and matrix tables

## Key Insights

The dashboard helps users:
- Identify categories and products with high return activity.
- Understand the main reasons behind product returns.
- Compare return performance across sales channels.
- Track refund amounts and return orders over time.
- Analyze the relationship between discounts and return rates.
- Support data-driven decisions to improve business performance.

## Business Benefits

This dashboard can help businesses identify potential product quality issues, improve product descriptions and sizing information, evaluate delivery performance, and develop strategies to reduce unnecessary returns and refunds.

## Project Purpose

This project demonstrates practical skills in data analysis, data visualization, dashboard design, and business intelligence. It is suitable for showcasing Power BI skills in a data analyst portfolio.

## Conclusion

The Return & Refund Analysis Dashboard transforms order and return data into an easy-to-understand business report. It helps users explore return patterns, monitor refund performance, and identify opportunities to improve customer experience and operational efficiency.
